How to Get Synced Lyrics in Musicolet (LRC Setup Guide)

Musicolet is one of the best offline Android players for synced lyrics. Here's how its LRC support works, where to put your files, and how to make your own.

Oct 2, 2026 5 min read

How Musicolet handles LRC

Musicolet reads standard .lrc files and highlights the current line as the song plays, with no internet required. It looks for a lyrics file next to the audio file with the same base name (for example, Song.mp3 and Song.lrc in the same folder). If a synced file isn't present, it can show plain lyrics instead, but those won't scroll in time.

Where to put the .lrc file

  • Place the .lrc in the same folder as the audio file.
  • Match the filename exactly, apart from the extension.
  • If it doesn't appear, rescan the folder or restart Musicolet so it picks up the new file.

Musicolet also reads the [ar:] and [ti:] metadata tags, and it honors the [offset:] tag, so a file with correct tags will slot in cleanly.

Fixing wrong timings in Musicolet

If the highlight is off, the fix is in the file, not the player. Musicolet lets you adjust a per-track offset in its lyrics settings, which is handy for a quick, uniform shift. For anything more than a consistent offset, edit the file itself: import it, nudge the offending lines, and re-export. See how to fix out-of-sync lyrics for the full approach.

Making your own LRC for Musicolet

When a synced file doesn't exist for your track (the usual case for niche songs, covers, and live versions), make one. Load the audio in Lyricron, add the lyrics, tap through the song once, and download the .lrc. Drop it next to the audio file with a matching name and Musicolet will pick it up.
