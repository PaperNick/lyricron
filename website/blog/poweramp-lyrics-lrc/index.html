Poweramp Lyrics: How to Add Synced LRC Files

Poweramp supports synced LRC lyrics with a bit of setup. Here's where the files go, how to get them to show, and how to make your own.

Oct 4, 2026 5 min read

How Poweramp handles lyrics

Poweramp shows synced lyrics from .lrc files and highlights the current line as the song plays. It looks for the lyrics file next to the audio, matched by filename, and it also reads the [ar:] and [ti:] metadata tags for display.

Where to put the .lrc file

  • Place the .lrc in the same folder as the audio file.
  • Match the filename, only the extension differs (song.mp3 + song.lrc).
  • Run a rescan in Poweramp's library settings if the lyrics don't appear right away.

Fixing drift in Poweramp

Poweramp applies the [offset:] tag, so a file with a correct offset will play in sync. If only part of the song drifts, the fix is in the file: import it, nudge the affected lines, and re-export. How to fix out-of-sync lyrics covers both the offset and per-line approaches.

Making your own LRC for Poweramp

When a synced file isn't available, make one. Load the audio in Lyricron, add the lyrics, tap through the song, and download the .lrc. Drop it next to the audio with a matching name and Poweramp will pick it up after a rescan. See how to sync lyrics to a song for the full walkthrough.
