foobar2000 Lyrics: Setting Up LRC Files

foobar2000 shows synced lyrics through add-on components. Here's how to set the panel up, load an .lrc file, and sync lyrics that aren't timed yet.

Oct 3, 2026 5 min read

The lyrics panel components

foobar2000 doesn't ship a lyrics view in the base install; you add one via a component like foo_lyrics (or a similar lyrics panel). Install the component, then add the panel to your layout from View > Layout. Once it's in place, it will display synced lyrics for the playing track when an .lrc is available.

Loading .lrc files

The lyrics panel looks for an .lrc file with the same base name as the audio, typically in the same folder. If the file isn't picked up, check the panel's settings for its lyric search paths and make sure the filename matches. foobar2000's lyrics components generally honor the [offset:] tag, so a file with a correct offset will play in sync out of the box.

Syncing unsynced lyrics

A lot of lyrics floating around are plain text with no timing at all. foobar2000 will show them, but they won't scroll in time. To turn plain lyrics into synced lyrics, time them yourself: load the audio and the plain text into Lyricron, tap through the song once, and export the timed .lrc. The step-by-step is in how to sync lyrics to a song.

Fixing drift

If the highlight runs early or late, use the panel's offset control for a uniform fix, or edit the file for anything more subtle. How to fix out-of-sync lyrics walks through both approaches.
