VLC Lyrics: How to Add and Sync LRC Files

VLC reads synced LRC files out of the box. Here's how to turn the lyrics view on, how to name files so VLC finds them, and how to fix timing when it's off.

Oct 3, 2026 5 min read

Enabling the lyrics view in VLC

VLC's lyrics panel is tucked away by default. Open View > VLsub (or enable it from the interface preferences) to reveal the lyrics window while a track plays. Once it's visible, VLC will show synced lyrics from any matching .lrc file it can find.

The file naming rules VLC expects

VLC matches an LRC file to its audio by filename. Put the .lrc in the same folder as the audio and give it the same base name, so song.mp3 pairs with song.lrc. If the names don't match, VLC won't load the lyrics automatically and you'll see an empty panel.

VLC is lenient about metadata tags, but a file with [ar:] and [ti:] can help when you're organizing a larger library.

Fixing offset in VLC

VLC lets you adjust a lyrics offset from the VLsub window, which is the quick fix when the whole file is uniformly early or late. For drift that changes through the song, the offset won't help, edit the file itself instead. The manual-fix workflow is in how to fix out-of-sync lyrics.

Making an .lrc for VLC

No synced file for your track? Make one in Lyricron: load the audio, add the lyrics, tap through once, and download the .lrc. Rename it to match the audio and drop it in the same folder. The full flow is in how to sync lyrics to a song.
